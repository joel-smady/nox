🗄 CASH DRAWER
// RJ11 drawer via printer port
How cash drawers work:
• Connect drawer RJ11 cable → printer's DK port
• Drawer opens via ESC/POS pulse — no USB needed
• Uses the same printer connection configured above
• Pin 2 pulse (25ms on / 120ms off) — compatible with
  Epson, Star, Bixolon, Citizen, and most generics
Drawer will also open automatically when:
• A cash sale is completed
• A split payment (cash portion) is made
• Toggle above to enable/disable auto-open
📷 BARCODE SCANNER
// USB HID plug-and-play
✓ No driver installation needed
USB barcode scanners emulate a keyboard — they work out of the box.
Setup:
  1. Plug scanner into any USB port
  2. Open the POS screen
  3. Click the product search box
  4. Scan a barcode — product loads instantly
Supported formats:
EAN-13 · EAN-8 · UPC-A · UPC-E · Code 128 · Code 39 · QR
Troubleshooting:
Nothing happens? → Click the search box first.
Wrong chars? → Set scanner to USB-HID mode (see manual).
Serial scanner? → Use USB-to-Serial adapter + serial port config.
BUNDLES & COMBOS
// combo products · meal deals · packs · stock auto-deducted per sale
How bundles work: Create a combo (e.g. "Meal Deal = Burger + Fries + Drink") with a single price. When sold from the POS, each component's stock is automatically deducted. Set the bundle price lower than the sum of parts to offer a discount.
